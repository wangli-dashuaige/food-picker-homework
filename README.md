# 今天吃什么随机选择器 🍜

一个非常简单、开箱即用的网页小工具：为「今天吃什么」这种世纪难题提供一点随机的小运气。
全部代码只由 HTML + CSS + 原生 JavaScript 写成，**零依赖、零构建、零外部请求**。

> 技术栈：HTML + CSS + 原生 JavaScript ｜ 依赖：0 个 ｜ 主文件：index.html

---

## 一、项目功能

| 功能 | 说明 |
| --- | --- |
| 默认食物清单 | 打开页面即有 8 种食物：火锅、麻辣烫、炒饭、饺子、汉堡、面条、烧烤、寿司 |
| 随机抽取 | 点击「🎲 帮我决定」，从当前清单里随机挑出一种，结果显示在页面中央的大卡片里 |
| 结果醒目展示 | 大号 Emoji + 大号文字，并带一个弹跳动画，一眼就能看到 |
| 添加食物 | 在输入框写下食物名，点击「➕ 添加食物」按钮（或直接按回车）即可加入清单 |
| 删除食物 | 每个食物右侧都有一个「✕」按钮，点一下就能从清单里移除 |
| 空输入保护 | 输入为空（或只有空格）时不会添加，输入框会抖动并提示原因 |
| 空列表保护 | 清单被删空后再点「帮我决定」，会提示「请先添加食物」，不会报错、不会卡死 |
| 重复保护 | 同一个食物不会重复加入清单 |

小细节：

- 常见食物会自动配上对应的 Emoji（🍲 🥟 🍣 …），自定义食物也会稳定地分到一个可爱图案。
- 添加 / 删除 / 抽取都会在清单下方给出一句反馈文字。
- 删除的正好是当前显示的结果时，结果区会自动回到引导文案，避免显示已不存在的食物。
- 按钮支持键盘操作和焦点样式，结果区使用 `aria-live` 播报，方便读屏软件。

## 二、如何运行

不需要安装 Node.js、不需要 `npm install`、不需要起服务器。

**方式一：双击打开（最简单）**

1. 找到项目文件夹 `王利-第三次作业`；
2. 双击 `index.html`；
3. 浏览器会自动打开页面，直接使用即可。

**方式二：拖进浏览器**

打开 Chrome / Edge / Firefox，把 `index.html` 文件直接拖进浏览器窗口。

**方式三：本地静态服务器（可选）**

如果想用 `http://` 地址访问，可在项目目录执行任意一种静态服务器命令：

```bash
# Python 3（自带）
python -m http.server 8000

# 或 Node.js
npx serve .
```

然后浏览器访问 `http://localhost:8000`。

> 说明：本项目不读写本地存储、不发起任何网络请求，所以用 `file://` 直接打开和用服务器打开，行为完全一致。

## 四、使用小贴士

- 想临时加菜：输入「酸菜鱼」→ 回车，清单里立刻多一项 🐟。
- 想换一家：点「✕」删掉不想吃的，再点「🎲 帮我决定」。
- 抽到的结果不满意？再点一次按钮就好，每次都是独立随机。
